# SPIDER-LINK

Личный штаб в стиле Spider-Verse: тест, каталог из **22 персонажей** с комиксными изображениями, паспорт героя, миссии, трофеи и сохранение обложки в PNG. Тест подбирает персонажа из всего каталога. Это расширяемая подборка, а не полный список всех пауков Marvel.

## Запуск

Нужен Node.js версии 22.13 или новее. Устанавливать зависимости для текущего сайта не требуется.

```sh
node scripts/serve-static.mjs
```

Откройте адрес, который напечатает команда: по умолчанию [http://127.0.0.1:5173](http://127.0.0.1:5173). Для другого порта:

```sh
node scripts/serve-static.mjs --port 5180
```

Если установлен npm, доступны равнозначные команды `npm run dev` и `npm start`. Локальный сервер слушает только этот компьютер.

## Изменения и сборка

Актуальный исходный сайт находится в `dist/`:

- `dist/index.html` — страница и навигация;
- `dist/style.css` — оформление;
- `dist/app.js` — каталог, подбор героя и взаимодействия;
- `dist/assets/` — комиксные изображения.

После изменений соберите переносимый файл:

```sh
node scripts/build-static.mjs
```

Или выполните `npm run build`. Команда проверит локальные изображения и соберёт `outputs/SPIDER-LINK.html` со встроенными стилями, логикой и картинками. Его можно открыть непосредственно в браузере; отдельная папка с изображениями не нужна. Для размещения на обычном статическом хостинге достаточно содержимого `dist/`.

Не редактируйте переносимый HTML вручную: следующая сборка заново создаст его из `dist/`. Внешние шрифты загружаются при наличии интернета; без сети используются системные шрифты.

## Проверка

```sh
node work/check.cjs
```

Или `npm test`. Проверки включают каталог, достижимость результатов теста, сохранение паспорта, миссии и трофеи. После изменений также проверьте в браузере изображения, поиск и скачивание обложки.

## Хранение данных

Паспорт, миссии и трофеи сохраняются в `localStorage` текущего браузера. Общего сервера, синхронизации, совместных комнат и приглашений пока нет. Данные при открытии отдельного HTML-файла и через локальный сервер могут храниться отдельно; очистка данных браузера удаляет прогресс.

## Сохранённый шаблон приложения

В репозитории остались исходные папки шаблона Vinext/React (`app/`, `components/`, `worker/` и другие). Они не используются для запуска текущего SPIDER-LINK. Обычные команды `dev`, `start` и `build` работают со статической версией из `dist/`.

Для отдельной работы с сохранённым шаблоном доступны команды `framework:dev`, `framework:build` и `framework:start`. Им нужны зависимости из `package-lock.json`. Сборка шаблона может перезаписать `dist/`, поэтому выполняйте такую работу в отдельной ветке или копии репозитория.

Фанатский неофициальный проект. Ссылки на источники изображений указаны у персонажей.
