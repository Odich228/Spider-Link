# SPIDER-LINK

Штаб для тебя и друзей в стиле Spider-Verse. Каталог из **199 персонажей и версий** с комиксными изображениями, тест, личный паспорт и обложка сохранены.

Добавлены все семь командных возможностей:

1. Комнаты с приглашением по ссылке и сохранением участников на сервере.
2. Паучий сбор: встреча, время, описание и ответы «В деле», «Буду позже», «Сегодня без меня».
3. Карта команды: паспорта участников и связи за совместные завершённые миссии.
4. Комикс-хроника: миссия превращается в выпуск с названием, историей и тремя фотографиями.
5. Командный PNG-постер с выбранными героями и собственными пауками.
6. Spider-Sona: имя, вселенная, способности, цвета костюма, линзы, эмблема и рисунок с живым предпросмотром.
7. Сравнение двух героев: комиксные изображения, вселенные, способности и источники.

## Быстрый запуск

Нужен **Node.js 24 или новее**. Зависимости устанавливать не требуется:

```sh
node server/main.mjs
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Равнозначные команды при наличии npm — `npm start` и `npm run dev`.

Создайте паспорт или собственного паука, откройте «Штаб команды» и создайте комнату. Кнопка приглашения копирует ссылку для друзей. Их браузеры должны иметь доступ к этому же работающему серверу.

## Свой сервер и домен

Готовы `Dockerfile`, `compose.yaml` и HTTPS-прокси Caddy. Инструкция находится в [deploy/README.md](deploy/README.md). Можно использовать свой Nginx/Caddy и запускать Node.js напрямую.

Настройки окружения:

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес, который слушает Node.js. В Docker — `0.0.0.0`. |
| `PORT` | `3000` | Порт приложения. |
| `PUBLIC_URL` | адрес запроса | Внешний адрес сайта, например `https://spider.example.com`. Задайте при работе через HTTPS-прокси. |
| `SPIDER_LINK_DATA_DIR` | `.spider-link` | Папка базы комнат и фотографий. |

Приложение не требует ChatGPT, внешней базы, платного API или отдельного сервиса фотографий. Внешние шрифты необязательны; без сети используются системные.

## Где хранятся данные

Комнаты, участники, сборы и миссии хранятся в SQLite, фотографии — рядом с базой. Данные переживают перезапуск. При обновлении приложения сохраняйте папку данных; в Docker она находится в отдельном томе `spider-data`.

Паспорт, избранное и Spider-Sona сохраняются в браузере и переносятся через JSON-копию в паспорте. Ключ входа в комнату хранится отдельно в браузере и не попадает в эту копию. Очистив браузер, можно снова войти по приглашению; появится новое подключение участника.

Комната доступна участникам с приглашением. Фотографии выдаются только после проверки доступа к своей комнате. Владелец может обновить приглашение: старая ссылка перестанет принимать новых участников, а подключённые друзья сохранят доступ.

Комнаты рассчитаны на 32 участников. Общие данные обновляются примерно каждые 6 секунд; обновление не стирает вводимый черновик. Историю и фотографии видят все участники этой комнаты.

## Исходники

- `dist/` — клиентский сайт и локальные комиксные изображения;
- `dist/catalog.js` — каталог, источники и профили игрового теста;
- `dist/team.js` — общий штаб, сборы, миссии, карта и хроники;
- `dist/extras.js` — собственный паук, сравнение и командные постеры;
- `server/` — HTTP-сервер, доступ к комнатам, SQLite и фотографии;
- `drizzle/` — версии схемы базы, применяемые при запуске;
- `docs/catalog-sources.md` — источники комиксного каталога.

Каталог расширяемый и пока не является полным реестром Marvel. У редких персонажей недостаток канонических сведений обозначен явно. Игровой тест не является канонической характеристикой Marvel.

## Сборка и проверка

```sh
node work/check.cjs
node --test server/*.test.mjs
node scripts/build-static.mjs
node scripts/package-server.mjs
```

Проверки покрывают 199 героев и 792 сочетания ответов, сохранение и импорт профиля, изоляцию комнат, приглашения, параллельные изменения, отчёты, фотографии и сохранность после перезапуска.

`build-static.mjs` создаёт `outputs/SPIDER-LINK.html` со встроенными изображениями и клиентскими функциями. Открытый отдельным файлом HTML работает в личном режиме; для общей комнаты используется серверная версия.

`package-server.mjs` создаёт переносимый архив `outputs/SPIDER-LINK-server.tar.gz` с готовым приложением, Docker и инструкцией, без данных пользователей и секретов. ZIP этой же сборки также может поставляться как готовый результат.

В исходном репозитории сохранены старые папки шаблона Vinext/React. Текущие команды `dev`, `start`, `build` запускают описанный здесь SPIDER-LINK; `framework:*` относятся к старому шаблону и не нужны для работы штаба.

Фанатский неофициальный проект для личного использования.
