# Запуск SPIDER-LINK на своём сервере

## Docker: пробный запуск

В папке приложения выполните:

```sh
docker compose up -d --build app
```

Откройте `http://localhost:3000` на том же сервере/компьютере. Для запуска этой проверки файл `.env` не требуется.

## Интернет-ссылка с HTTPS

1. Направьте DNS-запись своего домена на сервер и откройте входящие порты 80 и 443.
2. Скопируйте `.env.example` в `.env`.
3. Укажите свой домен в обеих строках: `SPIDER_LINK_DOMAIN=spider.example.com` и `PUBLIC_URL=https://spider.example.com`.
4. Запустите приложение и HTTPS-прокси:

```sh
docker compose --profile https up -d --build
```

Caddy получит сертификат и направит запросы в приложение. Откройте свой домен, создайте штаб и отправьте друзьям приглашение из интерфейса сайта. Серверное приложение по умолчанию не выставляет отдельный порт Node.js в интернет.

## Если уже есть Nginx или Caddy

Запустите только `app`, укажите внешний `PUBLIC_URL` и направьте существующий прокси на `http://127.0.0.1:3000`. Для Nginx увеличьте `client_max_body_size` как минимум до `512k`; клиент предварительно уменьшает фотографии до 350 КБ.

Пример отдельного Caddyfile на хосте:

```caddy
spider.example.com {
    encode zstd gzip
    reverse_proxy 127.0.0.1:3000
}
```

## Запуск без Docker

Нужен Node.js 24+. Для локальной проверки достаточно `node server/main.mjs`; установка npm-зависимостей не требуется.

Для постоянного запуска используйте свой менеджер служб и задайте `HOST`, `PORT`, `PUBLIC_URL` и `SPIDER_LINK_DATA_DIR`. Приложение корректно закрывает базу при SIGINT/SIGTERM. Миграции применяются при старте до обработки запросов.

## Обновление и данные

```sh
docker compose up -d --build app
docker compose logs --tail=100 app
```

Том `spider-data` сохраняет комнаты, участников, фотографии и миссии между сборками контейнера. Для резервной копии сохраните содержимое этого тома, предварительно остановив приложение. При запуске без Docker резервируйте папку `SPIDER_LINK_DATA_DIR` целиком.

Проверка работы сервера: `GET /api/health`. Коды приглашений и ключи браузеров не требуется добавлять в переменные окружения.
