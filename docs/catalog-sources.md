# Источники каталога SPIDER-LINK

199 персонажей и вариантов. Отдельная запись — другой персонаж или подтверждённая реальность; обычная смена костюма не считается новым героем. Это расширяемая подборка, а не исчерпывающий реестр Marvel. У редких фоновых персонажей источник может не раскрывать подробности истории и способностей.

Первые 22 позиции сохранены для совместимости старых паспортов. Профили теста — игровая интерпретация шести направлений ответов, не каноническая характеристика Marvel.
